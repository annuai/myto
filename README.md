# myto-moto

Motorcycle gear storefront. Next.js 16, Supabase, Razorpay, Resend.

```bash
npm install
npm run dev   # http://localhost:3000
```

Needs `.env.local`; see [docs/ops.md](docs/ops.md). Other docs: [architecture](docs/architecture.md), [supabase](docs/supabase.md), [commerce](docs/commerce.md).
